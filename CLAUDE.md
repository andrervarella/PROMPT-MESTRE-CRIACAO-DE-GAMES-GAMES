# CLAUDE.md — Orientações para Claude Code

Este repositório contém a metodologia universal, não o projeto de um jogo. Siga também `AGENTS.md`. Para criar ou revisar jogos, consulte `PROMPT_MESTRE.md` e só os módulos necessários; não releia tudo em tarefa trivial.

**Modelos:** parte criativa (conceito, história, direção de arte, especificação de assets) no modelo mais forte (Fable); execução (código, ajustes, integração) no Sonnet; Opus não é padrão. Detalhes e paralelismo em `modulos/MODELOS_E_PARALELISMO.md`.

Antes de editar: confira repositório, branch/commit e decisões aprovadas. Em projeto real, leia estado e handoff do **repositório do jogo**.

Depois de alterar: atualize a documentação pertinente e registre arquivos, testes efetivos, falhas e próxima ação. Commit/PR só quando permitido; informe se a mudança chegou à branch canônica.

Vale o Contrato de Evidência (seção 0 do `PROMPT_MESTRE.md`). Em divergências, sinalize o conflito e preserve decisões aprovadas.

# CLAUDE.md — Orientações para Claude Code

Este repositório contém a metodologia universal, não o projeto de um jogo. Siga também as convenções compartilhadas de `AGENTS.md` para manter consistência entre agentes. Quando a tarefa for criar ou revisar jogos, consulte `PROMPT_MESTRE_UNIVERSAL_GAMES_IA_V3.md` e os modelos necessários; não releia tudo em tarefas triviais.

Antes de editar: confira o repositório correto, branch/commit atual e decisões aprovadas. Em cada projeto real, leia o estado e o handoff do **repositório daquele jogo**; não presuma que uma conversa anterior ou outro agente foi sincronizado.

Depois de alterar: atualize documentação pertinente e registre arquivos, testes efetivos, falhas e próxima ação. Faça commit/PR apenas quando permitido e informe explicitamente se a mudança chegou à branch canônica.

Não use informação antiga de chats como prova de que um recurso funciona. Não invente arquivos ou testes nem substitua assets oficiais. Em divergências, sinalize o conflito e preserve as decisões aprovadas.

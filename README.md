# PROMPT MESTRE UNIVERSAL — CRIAÇÃO DE GAMES COM IA

**Versão vigente: V3.0** · Metodologia compartilhada para ChatGPT, Claude, Codex e outras IAs.

Este repositório público contém **o método universal para criar e aprimorar jogos com IA**, independentemente de gênero, engine, universo, personagens ou plataforma. **Não** é o repositório do código de um jogo específico.

## Comece aqui

1. Leia o [PROMPT MESTRE UNIVERSAL V3.0](PROMPT_MESTRE_UNIVERSAL_GAMES_IA_V3.md). O documento orienta do conceito, GDD e hook à produção, assets reais, QA e entrega.
2. Se for um agente de programação, consulte também [AGENTS.md](AGENTS.md); para Claude Code, consulte [CLAUDE.md](CLAUDE.md).
3. Para **cada jogo**, mantenha código e estado no **repositório específico do jogo**. Copie ou adapte os arquivos de [MODELO_PROJETO/](MODELO_PROJETO/).
4. Ao iniciar a sessão, confira **repositório, branch, commit, ESTADO_ATUAL, DECISOES e HANDOFF** do projeto em questão. Ao encerrar, atualize esses documentos e faça commit/PR se autorizado.
5. Informe o hash do commit ou URL do PR para comprovar sincronização. Não confunda mudanças locais ou branches não integradas com o estado oficial em `main`.

## Como pedir a outra IA

> Consulte o repositório público `https://github.com/andrervarella/PROMPT-MESTRE-CRIACAO-DE-GAMES-GAMES` e leia o Prompt Mestre Universal V3.0. Use-o como método, mas execute e registre o trabalho no repositório específico do jogo que eu indicar. Antes de modificar, confira branch e commit, decisões e estado atual. Depois reporte as mudanças, testes e o commit/PR efetivamente publicado.

## Regras de colaboração

- **Fonte de verdade:** as regras universais ficam aqui; cada jogo mantém o próprio GDD, assets, histórico e estado.
- **Um único fluxo:** ChatGPT, Claude e Codex devem consultar a revisão mais recente antes de trabalhar. Nenhuma IA compartilha automaticamente a memória de outra.
- **Sem regressão silenciosa:** respeitar decisões aprovadas, evitar sobrescrever commits e validar mudanças relevantes.
- **Entrega real:** não apresentar código inexistente, sprites fictícios ou testes não executados como completos.
- **Público:** não subir tokens, senhas, materiais privados, imagens de clientes ou arquivos protegidos sem autorização.

**Observação:** Claude Code pode reconhecer `CLAUDE.md` em um projeto ao qual tenha acesso. Claude em chat e outras IAs dependem da capacidade real de abrir links ou ler arquivos; simplesmente citar um repositório não garante que a ferramenta o acessou.

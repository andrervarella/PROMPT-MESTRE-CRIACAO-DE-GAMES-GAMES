# CHANGELOG — METODOLOGIA UNIVERSAL DE GAMES COM IA

Este arquivo registra **mudanças aprovadas e publicadas** na metodologia universal. Não confundir alterações do método com mudanças em jogos específicos.

## [3.0] — 2026-11-10

- Publicado o Prompt Mestre Universal V3.0 como referência canônica.
- Consolidado o fluxo **Modo A (descobrir e preparar)** e **Modo B (executar)**.
- Preservadas as práticas de oportunidade, hook, GDD, direção artística, assets reais, implementação e QA.
- Formalizado o protocolo de continuidade ChatGPT ↔ Claude ↔ Codex: branch, commit, estado, decisões, handoff e validação.
- Adicionados `AGENTS.md`, `CLAUDE.md` e `MODELO_PROJETO/` para orientar novos projetos.
- Estabelecida a separação: **metodologia universal neste repositório; código e estado de cada jogo em seu próprio repositório**.

## Como registrar futuras atualizações

Para cada nova versão, anote data, mudança, justificativa, impacto/compatibilidade, arquivos alterados e commit ou PR. Não atualize a referência canônica com apenas uma sugestão ainda não validada. Se outro agente estiver trabalhando simultaneamente, proponha a mudança via branch e pull request, evitando sobrescrever alterações.
